# Release highlights

AbilityFramework v3 introduces several core new features and architectural improvements.

See [Architecture evolution design](/en/guide/release-highlights/architecture-evolution)

## Documentation index

- [Skill](/en/guide/release-highlights/skill) — ability packages carry AI-Agent skill documents; the framework hosts and discovers them uniformly
- [Ability instances](/en/guide/release-highlights/instance) — separating CR templates from runtime instances, supporting concurrent instances and frozen configuration
- [Logging system](/en/guide/release-highlights/log) — a unified logging layer that hides the differences between the glog and insightos-log backends
- [Zenoh remote execution](/en/guide/release-highlights/zenoh) — launch ability processes remotely via the Zenoh protocol
