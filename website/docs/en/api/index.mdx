# API overview

AbilityFramework exposes two kinds of interfaces:

- **HTTP REST API** — listens on `0.0.0.0:8080` by default, for Studio / MCP Server / integrators, covering the full feature set: ability instance lifecycle, resource management, ability package management, Skill documents, discovery and teams.
- **SDK** — Python / C++ / Go SDKs that encapsulate the interface definitions, heartbeat management, and lifecycle callbacks needed for ability development, for ability developers writing ability processes.
