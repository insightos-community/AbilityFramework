# C++ SDK

> Repository name: `ability-sdk`

The C++ SDK provides classes such as `AbilityStub`, `AbilityConfig`, and `TaskHelper` for writing C++ ability processes.

:::info
The C++ SDK documentation is being written. The following is a summary of known information.
:::

## Core classes

| Class | Purpose |
|---|---|
| `AbilityStub` | Ability process entry point; handles heartbeat reporting and lifecycle responses |
| `AbilityConfig` | Reads configuration parameters from the CR |
| `TaskHelper` | Helper for task registration and execution |
