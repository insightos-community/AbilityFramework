# API 概览

AbilityFramework 提供两类对外接口：

- **HTTP REST API** — 默认监听 `0.0.0.0:8080`，供 Studio / MCP Server / 业务集成方调用，覆盖能力实例生命周期、资源管理、能力包管理、Skill 文档、发现与团队等全部功能。
- **SDK** — Python / C++ / Go 语言 SDK，封装能力开发所需的接口定义、心跳管理、生命周期回调，供能力开发者编写能力进程。
