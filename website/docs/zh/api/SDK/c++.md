# C++ SDK

> 仓库名：`ability-sdk`

C++ SDK 提供 `AbilityStub`、`AbilityConfig`、`TaskHelper` 等类，用于编写 C++ 能力进程。

:::info
C++ SDK 文档正在编写中。以下为已知信息摘要。
:::

## 核心类

| 类 | 用途 |
|---|---|
| `AbilityStub` | 能力进程入口，处理心跳上报与生命周期响应 |
| `AbilityConfig` | 读取 CR 中的配置参数 |
| `TaskHelper` | Task 注册与执行辅助 |
